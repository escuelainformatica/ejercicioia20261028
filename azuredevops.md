# azure devops deployment

* Cree un archivo yaml (azure-pipelines.yml) que sirva para automatizar el despliegue de la aplicacion web contable en Azure DevOps.
* Tiene que hacerse las pruebas unitarias y de integracion antes de hacer el despliegue.
* Y ademas debe colectar informacion de cobertura de pruebas y subirla a Azure DevOps para su analisis.
* Use la ultima version de Ubuntu LTS disponible en Azure DevOps.
